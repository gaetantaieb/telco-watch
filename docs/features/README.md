# Feature briefs

One file per feature or fix, written by the `product-owner` agent
(`.claude/agents/product-owner.md`) before development: problem, functional design,
rules and edge cases, and numbered acceptance criteria that the `qa` agent turns into
tests. `docs/spec.md` stays the description of the current version; a brief records
what was agreed for one change and its `Status:` (draft, agreed, delivered).
